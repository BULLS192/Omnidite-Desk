# Omnidite Desk Beta Channel

This branch is the **opt-in testing channel** for future Desk releases. It is based on stable `main` V0.6.0 and contains no unreviewed experimental code at initialization.

- Use Desk → Updates → Channel **Beta** → Switch to Beta, only after installing the V0.6 native updater helper.
- Use **Stable** → Switch to Stable to return to released code. This reverts code, not Chrome-local data.
- Beta changes must remain fast-forward descendants of current stable main. Before advancing Beta, incorporate new main releases.
- Never put personal backups, tokens, Google Calendar data, or credentials in this branch.
- Release qualification: Actions pass, main compatibility maintained, backups verified, manual Chrome acceptance recorded before promotion.

For beta release notes, track changes via the Desk update panel’s fixed GitHub commits link.
